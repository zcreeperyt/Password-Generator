# 🔐 Password Generator

A simple yet powerful password generator with a GUI, built using **Python** and **Tkinter**. Perfect for creating secure, random passwords for various purposes.

## 📌 Features
- Generates secure passwords with a custom length
- Simple GUI using **Tkinter**
- Copy generated password directly to the clipboard
- Modern design for a clean user interface

## 🚀 Installation
1. **Install Python** (if not already installed): [Download Python](https://www.python.org/downloads/)
2. **Install required libraries:** Open a terminal and run:
   ```sh
   pip install pyperclip
3. **Download project files and run the script:**
 ```sh
python password_generator.py
```
