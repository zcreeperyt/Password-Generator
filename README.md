# 🔐 Password Generator

A simple yet powerful password generator with a GUI, built using **Python** and **Tkinter**. Perfect for creating secure, random passwords for various purposes.

## 📌 Features
- Generates secure passwords with a custom length
- GUI based

## ♨️ Installation

# IMPORTANT: MAKE SURE YOU HAVE PYTHON INSTALLED! OTHERWISE IT WON'T WORK!

1. Download the password generator from the [releases](https://github.com/zcreeperyt/Password-Generator/releases) tab.
3. Extract the zip to a place of your choice.
4. Run the script.
